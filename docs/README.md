# Documentation Reference

Folder ini menjadi referensi implementasi untuk aplikasi forwarding lokal BUMI.

## Struktur
- `00-overview` ringkasan konteks bisnis dan cakupan
- `01-product` PRD dan sasaran produk
- `02-information-architecture` menu, route, dan navigasi responsif
- `03-modules` detail requirement per domain
- `04-workflows` alur proses utama lintas modul
- `05-data-model` entity dan status inti
- `06-ui-ux` aturan desain dan responsivitas
- `07-implementation` roadmap dan struktur teknis
- `08-qa` checklist validasi dan uji responsif
- `09-decisions` pertanyaan terbuka dan keputusan arsitektur

## Cara Pakai
1. Mulai dari `01-product/prd-forwarding-local.md` untuk memahami ruang lingkup produk.
2. Gunakan `02-information-architecture/menu-structure.md` dan `02-information-architecture/route-map.md` saat membuat routing.
3. Ikuti dokumen di `03-modules` dan `04-workflows` saat mengimplementasikan fitur.
4. Jadikan `07-implementation/technical-folder-structure.md` sebagai acuan penempatan file.
5. Gunakan `08-qa/qa-checklist.md` sebelum merge atau demo.
