# Responsive Navigation

## Desktop
- Sidebar tetap untuk domain utama dan menu sekunder
- Header berisi global search, branch context, notifications, dan user menu

## Mobile
- Bottom navigation untuk `Home`, `Commercial`, `Ops`, `Finance`, `More`
- `More` membuka sheet atau drawer untuk Master Data, Settings, dan halaman sekunder
- Halaman detail menggunakan top bar dengan back action yang jelas

## Rules
- Menu mobile tidak boleh menampilkan semua item desktop satu per satu
- Aksi utama halaman harus tetap terlihat tanpa scroll panjang
- Filter kompleks dipindah ke bottom sheet atau collapsible panel
- Table-heavy screens wajib punya card variant untuk mobile
