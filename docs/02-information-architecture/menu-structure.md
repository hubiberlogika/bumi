# Menu Structure

## Analisa Menu Saat Ini
Menu saat ini sudah mencakup Overview, Sales, Quotations, Operations, Warehouse, Finance, dan Settings. Struktur ini memberi arah domain, tetapi belum merepresentasikan lifecycle bisnis dari pengajuan sampai finance.

## Menu Target
- Overview
- Quotations
- Operations
- Finance
- Mitra
- Settings

## Prinsip Penyusunan
- Menu mengikuti alur bisnis, bukan sekadar daftar halaman
- Domain utama tampil di navigasi utama
- Halaman master dan konfigurasi ditaruh di area sekunder
- Mobile navigation hanya memuat domain primer

## Gap Dari Menu Saat Ini
- `Warehouse` belum wajib untuk MVP forwarding vendor-based
- Finance di mobile belum menjadi domain primer
 - Data partner masih perlu ditampilkan sebagai menu bisnis, bukan disembunyikan di label master data yang terlalu generik
