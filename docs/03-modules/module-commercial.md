# Module Commercial

## Tujuan
Mengelola aktivitas awal bisnis dari quotation sampai siap diteruskan ke operations dan finance.

## Halaman Inti
- Quotations

## Kemampuan Utama
- Menyimpan data customer dan kebutuhan shipment awal
- Membuat quotation dengan selling items
- Mengelola approval quotation
- Mengirim quotation ke customer dan mencatat hasilnya

## Entitas Utama
- Quotation

## Status Utama
- Quotation: draft, waiting_approval, approved, sent, customer_approved, converted

## Responsive Notes
- List quotation harus punya mobile card view
- Form quotation dibagi per section: customer, route, service items, notes
- Quick actions di mobile harus menonjolkan create quotation dan lanjut ke shipment
