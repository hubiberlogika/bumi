# QA Checklist

## Navigation
- Desktop sidebar menampilkan domain utama dengan urutan yang benar
- Mobile navigation menampilkan Home, Quotation, Ops, Finance, Mitra, dan More
- Active state konsisten pada desktop dan mobile

## Responsive
- Dashboard tetap terbaca pada 360px width
- List transaksi berubah menjadi card layout di mobile
- Form panjang tetap nyaman tanpa zoom paksa
- Action utama tetap terlihat di mobile

## Commercial
- Quotation mengikuti approval flow
- Conversion ke shipment hanya bisa dari quotation approved

## Operations
- Shipment menyimpan mode, route, dan milestone
- Vendor PO bisa dibuat dari buying items
- Dokumen operasional terkait ke shipment yang benar

## Finance
- Invoice customer terkait ke shipment atau quotation yang benar
- AR dan AP berubah saat payment dicatat
- Summary report konsisten dengan transaksi dasar

## Master Data
- Mitra customer, vendor, dan transporter dapat disimpan dengan benar
- Branch ownership membatasi visibilitas data
- User dan role mengikuti permission map
